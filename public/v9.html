Set up TradingView securely
  1. Create a Cloudflare KV namespace and bind it to this Pages project as TV_EVENTS.
  2. Create an encrypted TRADINGVIEW_WEBHOOK_TOKEN secret (32+ random characters) and set private TV_OWNER_UID for the account allowed to view alerts.
  3. Redeploy Cloudflare Pages, then configure an HTTPS TradingView alert using /api/tv-alert and TradingView's supported JSON schema. Enable TradingView two-factor authentication.
  4. Send a harmless test alert and confirm receipt here. Never put broker passwords or Anthropic keys in webhook messages.
TradingView webhook documentation ↗
Set up scheduled market scans
  1. Create a KV namespace and bind it as SCANNER_SNAPSHOTS to both your Pages project and the separate scanner Worker.
  2. Set authorized market-data secrets on the Worker and enable the licensed feed.
  3. Deploy wrangler.scanner.toml with the real KV namespace ID, and confirm scheduled executions in Cloudflare logs.
  4. After a market-hours run, check that a validated snapshot exists before opening it here.

These are optional research alerts, never brokerage execution. A connected resource is not proof that an alert or scheduled scan has successfully run.
